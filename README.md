One original one-line office joke, written for the make.fun One-Line Office Joke Laugh-Off. A judge model reads the entries two at a time and keeps the funnier one; the line aims for a sharp, surprising punchline that lands on one read.

## Run it

```sh
node main.ts
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), one line, 1–200 characters, no network, no randomness — the same line on every run.
